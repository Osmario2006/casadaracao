# Casa da Ração — catálogo de pedidos

Site de pedidos da Casa da Ração (Av. Camilo Calazans, 394, Novo Paraíso, Aracaju/SE).
O cliente escolhe os produtos, monta o pedido e envia a mensagem pronta para o WhatsApp da loja.

## Como editar produtos e preços
Abra `index.html` e procure a lista `PRODUTOS` dentro do `<script>`.
Cada produto tem `preco` (ex.: `89.9`); use `null` para mostrar "Valor no WhatsApp".
O número da loja fica em `WHATSAPP`.

Publicado com GitHub Pages a partir da branch `main`.
